# 🎓 AdaptiveLearningPlatform
Это образовательная **ИИ-платформа**, которая позволяет изучать любую тему всего в **пару кликов**.

### 🔐 Начало работы

Чтобы начать обучение, пользователю необходимо:
	•	👤 Войти в систему или создать новый аккаунт
	•	🔑 Указать ключ Yandex GPT

После этого открывается полный доступ ко всем возможностям платформы.

### 📚 Обучение

Пользователь может:
	•	📖 Выбрать тему из списка, созданного другими пользователями
	•	✍️ Создать собственную тему для изучения

На основе:
	•	названия темы
	•	дополнительной информации

*🧠 Нейросеть автоматически формирует персональный план обучения, разбивая материал на логичные и последовательные подтемы.*

### 💬 ИИ-преподаватель

Каждую подтему можно изучать в интерактивном чате с 🤖 ИИ-учителем, который:
	•	💡 объясняет сложные моменты
	•	❓ отвечает на вопросы
	•	🧭 направляет и помогает в процессе обучения

### 📝 Итоговый тест

По завершении обучения пользователь проходит финальный тест, включающий:
	•	📘 теоретические задания
	•	🛠 практические задачи

Тест помогает:
	•	✅ проверить уровень усвоения материала
	•	🧠 закрепить полученные знания
	•	🎯 понять, действительно ли тема была освоена

*✨ Учись в удобном темпе, с персональным планом и ИИ-помощником ✨*
